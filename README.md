# 🚀 ProgressMindAI

An AI-powered productivity assistant that helps users plan their day, stay focused on their goals, and reflect on their progress using AI.

ProgressMindAI combines structured planning with intelligent reflection to help users build consistency, improve productivity, and make meaningful progress every day.

---

## ✨ Features

### 🌅 Morning Planner

Generate personalized daily plans based on goals, priorities, and available time.

### 🌙 Evening Review

Reflect on completed work, identify wins and challenges, and prepare for the next day.

### 🤖 AI-Powered Insights

Uses Gemini AI to generate meaningful plans, reflections, and recommendations.

### ⚡ FastAPI Backend

Built with FastAPI for speed, scalability, and clean API development.
